# Pickle_box

천상인 님(@nomadwonsiin)의 피클(Pickle) AI 비서 전용 작업 및 연동 저장소입니다.

## 디렉토리 구조

| 디렉토리 | 역할 |
| --- | --- |
| `docs/` | 비서 업무 산출물, 지식창업 자료, 리포트 |
| `scripts/` | 업무 자동화 및 분석 스크립트 |
| `notes/` | 정기 브리핑 아카이브 및 메모 |

## 사용 규칙

- 새 산출물은 성격에 맞는 디렉토리에 둡니다.
- 임시 파일과 시스템 파일은 `.gitignore` 규칙에 따라 커밋하지 않습니다.
- 커밋 메시지는 변경 내용을 한 줄로 요약합니다. (예: `feat: ...`, `docs: ...`, `fix: ...`)
